# Мир Оптики — Система оформления заказов

## 1. Название приложения

**Мир Оптики**

## 2. Используемые технологии

- **Язык:** Python 3.13+
- **GUI:** PySide6 6.8+
- **СУБД:** PostgreSQL 18.6
- **Драйвер БД:** psycopg2-binary 2.9.10+

## 3. Назначение и основные функции

Приложение автоматизирует продажи в магазине оптики. Функции:

- Каталог товаров
- Авторизация по логину
- Роли
- Фильтрация по категории, сортировка по цене, поиск по названию
- Подсветка товаров со скидкой > 15%
- Подсветка товаров без остатка
- Перечёркнутая старая цена и итоговая цена со скидкой
- Оформление заказа
- Управление заказами (Менеджер, Администратор)

## 4. Порядок подготовки БД и запуска

1. Установите PostgreSQL 18.6.
2. Выполните `db/opticworld.sql` в pgAdmin.
3. Выполните `db/import.py` в VS Code.
4. Установите зависимости: `pip install -r requirements.txt`.
5. Запустите: `python main.py`.
